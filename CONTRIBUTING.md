# Contributing to rl_rob

Thank you for your interest in rl_rob. Contributions that keep the library transparent and suitable for teaching are welcome.

## Reporting problems and asking for help

Please open an issue at <https://github.com/AltahhanAi/rl_rob/issues>. For a bug, include the code you ran, the full error message, and your Python, NumPy and PyTorch versions.

## Suggesting changes

1. Fork the repository and create a branch for your change.
2. Keep the style of the library: each update rule should stay readable in a few lines, and every algorithm should keep the common `Algorithm(env=..., ...).interact()` interface.
3. Add or update a test in `tests/` and run `pytest` before opening a pull request.
4. Open a pull request describing what the change does and why it helps learners or instructors.

## Using rl_rob in your own teaching

You are welcome to use rl_rob in your courses under the AGPL-3.0 licence. If you do, a short note in an issue telling us about your course is appreciated, and helps the project.
